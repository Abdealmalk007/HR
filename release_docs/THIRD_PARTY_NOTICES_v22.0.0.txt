إشعارات مكونات الطرف الثالث — ProTech HR v22.0.0
====================================================

هذا الملف يوضح المكونات المفتوحة المصدر التي أضيفت أو ثُبتت ضمن عملية بناء
الإصدار 22.0.0. لا يغيّر هذا الإشعار حقوق أصحاب المكونات أو شروط تراخيصهم.

1) DejaVu Fonts
---------------
الاستخدام: تضمين خط يدعم العربية داخل تقارير PDF بدل الاعتماد الكامل على
الخطوط المثبتة في Windows.

الموقع داخل المصدر:
assets\fonts\DejaVuSans.ttf
assets\fonts\LICENSE_DEJAVU.txt

المشروع: https://dejavu-fonts.github.io/
الترخيص الكامل مرفق في الملف المذكور أعلاه.

2) Tcl/Tk 8.6.15
---------------
الاستخدام: بيئة واجهة Tk الرسومية المضمّنة مع النسخة التنفيذية Windows x64.

الموقع داخل المصدر:
build_assets\tk_runtime\_tk_data\license.terms
build_assets\tk_runtime\_tcl_data\license.terms

Tcl/Tk برنامج مفتوح المصدر بتراخيص BSD-style. النصوص الكاملة المرفقة مع
المكونات هي المرجع القانوني المعتمد.

3) Python والمكتبات
-------------------
يستخدم التطبيق Python ومكتبات موضحة بإصدارات مقفلة في:
requirements.txt
requirements-build.txt

تخضع كل مكتبة لترخيصها الأصلي. ملفات METADATA وLICENSE المتاحة ضمن الحزمة
أو بيئة البناء تبقى المرجع التفصيلي لشروط كل مكتبة.

4) Inno Setup 7
-------------------
الاستخدام: بناء ملف تثبيت Windows. لا يُوزع المترجم نفسه ضمن حزمة التطبيق.
أعلن المترجم المستخدم أثناء البناء عبارة "Non-commercial use only"؛ لذلك يجب
على الناشر توفير ترخيص مناسب من صاحب الأداة قبل استخدام المُثبّت أو توزيعه
لأغراض تجارية. شروط صاحب الأداة هي المرجع القانوني.

ملاحظة
------
لا تتضمن هذه الإشعارات أي شهادة توقيع رقمي. توقيع Authenticode الحقيقي
يتطلب شهادة سارية مملوكة للناشر، وقد أُرفقت سكربتات إعداد التوقيع والتحقق
لتشغيلها عند توفير الشهادة.
