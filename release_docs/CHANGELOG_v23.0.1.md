# سجل تغييرات ProTech HR v23.0.1

## التصدير والتقارير

- إصلاح تعطل زر Excel عند تمرير `company_profile`.
- إصلاح تعطل زر HTML للسبب نفسه، وإرجاع المسار النهائي الصحيح للتقرير.
- إضافة تقرير موظف PDF وExcel من صفحة التقارير مع قائمة واضحة لاختيار الموظف.
- إضافة زر Excel فاخر بجوار تقرير PDF في صفحة الموظفين.
- إنشاء ملف موظف متعدد الأوراق: الملخص التنفيذي، البيانات، ملخص الحضور، الحضور، الإجازات، المستندات، الحقول المخصصة، وبيانات الشركة.
- تحسين هوية Excel بعناوين كبيرة، ألوان مؤسسية، اتجاه RTL، تجميد العناوين، وفلاتر تلقائية.

## الواجهة وسهولة الاستخدام

- إعادة ترتيب صفحة التقارير إلى بطاقات واضحة للتقارير العامة وتقارير الموظفين.
- إضافة ملاءمة مركزية تلقائية لكل النوافذ المنبثقة حسب دقة الشاشة ومساحة شريط المهام.
- الحفاظ على التمرير وجميع الحقول والأزرار والميزات دون حذف.

## التشغيل

- إزالة تفعيل أغلفة الترقيع القديمة من مسار التشغيل ومن الحزمة التنفيذية.
- تشغيل وحدات Excel وHTML وقاعدة البيانات مباشرة لتقليل التعارض وتسريع البدء.
- ترقية رقم الإصدار التنفيذي والمثبت إلى 23.0.1.
